## วิธีตรวจ

1. ดึงโจทย์สัปดาห์ 9 ทั้งหมดจาก JSON และอ่านเฉลยทีละข้อ
2. คำนวณคำตอบเชิงตัวเลขทุกข้อใหม่ด้วย python แล้วเทียบกับเฉลยของชุดโจทย์
3. สำหรับแต่ละข้อ อ่านบทเรียน **ก่อนแก้** แล้วตัดสินว่าคนที่อ่านเฉพาะบทเรียนตอบได้หรือไม่ (ตัดสินจากการอ่านของผมเอง ไม่ได้ให้ผู้ตัดสินอิสระมาทดลองทำ)
4. เติมสิ่งที่ขาดลงบทเรียน แล้วตัดสินซ้ำ

เกณฑ์ที่ใช้: **A** = ตอบได้จากข้อเท็จจริงที่บทเรียนมีอยู่แล้ว (รวมการตัดตัวเลือกผิดทีละตัวด้วยข้อเท็จจริงในบทเรียน), **B** = ต้องอาศัยข้อเท็จจริงที่บทเรียนไม่ได้เขียนไว้ชัด ต้องเดาหรือใช้ความรู้นอกบทเรียน, **C** = ตอบไม่ได้

สิ่งที่ผมไม่ได้ทำ: ไม่ได้เปิดไฟล์ `bank_q*.md`, `solve_*.md` และไม่ได้เทียบทีละข้อกับ `q_sonnet.md`, `q_codex.md`, `q_gemini.md` ผมใช้ `questions_legacy.json` เป็นตัวแทนชุดม็อกสามชุด (ข้อสัปดาห์ 9 ในชุดม็อกคือ cm11-cm20 และ cf2, sm11-sm20 และ sf2, gm11-gm20 และ gf2) โดยอาศัยที่เห็นว่าหัวข้อใน `q_sonnet.md` (Q11-Q15 เป็น W9) ตรงกับ id เหล่านี้ ถ้าชุดม็อกจริงมีข้อที่ไม่อยู่ใน JSON จะไม่ถูกนับในรายงานนี้

## ผลคำนวณซ้ำของเฉลยเชิงตัวเลข

ผมคำนวณซ้ำทุกข้อที่มีตัวเลขด้วย python (ตัวอย่าง: 2,304 มิติ, n(n−1)/2 ของ 1,000 / 2,000 / 10,000 ประโยค, ขนาดหน่วยความจำ 2M × 384 / 5M × 768 / 20M × 768 / 200M × 384, triplet loss ทุกค่า, cosine ของ a = [3,4], p = [4,3], n = [5,12], อัตราส่วน 9,862 เท่า, 255/31 = 8.2258, MSE ของ label ที่ไม่ normalize = 6.25, Recall@10 = 0.75 และ MRR = 0.6667, ผลต่างคะแนน STS 29.85 / 11.67 / 30.68) พบว่า **เฉลยทุกข้อตรงกับค่าที่คำนวณได้** ไม่พบข้อที่เฉลยผิดเชิงตัวเลข
