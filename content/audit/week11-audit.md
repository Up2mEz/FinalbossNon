## ข้อขัดแย้งและข้อที่ตอบไม่ได้ (ที่บันทึกไว้ ไม่ได้เลือกข้างเงียบ ๆ)

1. **hints ติดป้าย "Week 11" ให้ quantization และ compression แต่สไลด์ DL-11 และเดโมสัปดาห์ 11 ไม่มีเลย** ตรวจด้วยการค้นคำว่า quantiz, pruning, distill ได้ 0 ครั้งในทั้งสองไฟล์ ส่วนสไลด์ DL-10 มี 42 ครั้ง คลังข้อสอบจำลองก็จัดข้อ quantization (Q30 ของชุด Codex) ไว้ในสัปดาห์ 10 แปลว่าเลขสัปดาห์ของวิดีโอไม่ตรงกับเลขสไลด์ (เป็นข้อสรุปจากหลักฐานอ้อม ยังไม่ได้เปิดดูวิดีโอ) การจัดการ: เพิ่มตัวอย่างและตัวชี้ใน week11.md และไม่แก้ week10.md
2. **ข้อ n11-L4-02 ใช้จำนวนโมเดลของ GRPO ขึ้นกับว่ามี neural reward model หรือไม่** สไลด์ 50 เขียน "Reward Model (or rule checker)" และเดโมเขียนว่า GRPO ไม่ต้องมี reward model หรือ value function แยก ข้อสอบข้อนี้ระบุในโจทย์ว่าใช้ neural reward model จึงนับ 3 โมเดล (78 GB) ถูก แต่ถ้าโจทย์จริงใช้ rule checker จำนวนโมเดลจะเหลือน้อยกว่านั้น นักเรียนต้องอ่านโจทย์ ไม่ควรจำว่า GRPO = 3 โมเดลเสมอ
3. **"Majority vote" ในสไลด์เทียบกับเฉลยของข้อ n11-L4-03** สไลด์เขียน "Majority Voting" แต่เฉลยของข้อนี้ให้ 18 ชนะด้วย 3 จาก 7 เสียง (ไม่เกินครึ่ง) ซึ่งเป็นการนับแบบเสียงมากที่สุด (plurality) เปเปอร์เองใช้คำว่า "most consistent answer" บทเรียนจึงเขียนว่าชนะด้วยเสียงมากที่สุด สไลด์ไม่ได้ระบุวิธีเมื่อเสมอ
4. **ตาราง DPO vs GRPO ในเดโมเขียน baseline ของ DPO = "Reference model"** ส่วนสไลด์ 40-41 พูดถึง reference ในฐานะตัวหารของ log-ratio ไม่ได้เรียกว่า baseline ถ้าข้อสอบใช้คำว่า baseline ตามเดโม ให้ตอบว่า reference model (มาจากเดโม ไม่ใช่สไลด์)
5. **β ใน DPO: loss ลดลงเมื่อ β เพิ่ม แต่ความหมายคือ β ใหญ่ = ใกล้ reference** ไม่ใช่ข้อขัดแย้งจริง แต่เป็นกับดัก: ใน toy batch ของเดโม logit ≥ 0 ทั้งหมด β มากจึงทำให้ loss ต่ำ บทเรียนระบุไว้ทั้งสองด้านแล้ว
6. **ข้อ sm40 และ n11-L1-02 ตอบไม่ได้จากสไลด์** เป็นเนื้อหาเดโมล้วน ซึ่งตรงกับที่อาจารย์บอกว่าอาจมี 1-2 ข้อ จึงเพิ่มส่วนเดโม
7. **ตัวเลข PPO "ประมาณ 4 เท่า"** (สไลด์ 49) ใช้เป็นการประมาณเท่านั้น ข้อ n11-L4-02 ใช้ 4 โมเดลเท่ากันหมด ซึ่งสอดคล้องกับสไลด์ แต่ในทางปฏิบัติ critic หรือ reward model อาจเล็กกว่า actor (บทเรียนเดิมบันทึกไว้แล้ว)
8. **แถวสถานะ fill-in ในไฟล์ JSON ของ gen/gen2 ไม่มีฟิลด์ ans** (เฉลยอยู่ในฟิลด์ key และ note) ผมอ่านเฉลยจากฟิลด์เหล่านั้น: n11-L3-F3 = 0.5; 0.4741, n11-L4-F4 = 0.4; −2; 0.5, n11-X4-F5 = 0.6931; 0.3133; 2 ตรวจด้วย python แล้วตรงกัน
