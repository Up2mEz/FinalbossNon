# NLP Final Exam Study (สัปดาห์ 8 ถึง 14)

เนื้อหาติวสอบไฟนอลวิชา Natural Language Processing with Deep Learning ตามสไลด์ NLP-DL-08 ถึง NLP-DL-14

## โครงสร้าง

| ตำแหน่ง | คืออะไร |
|---|---|
| `content/week08.md` ถึง `week14.md` | เนื้อหาติวรายสัปดาห์ (ต้นฉบับที่แก้ไขได้) |
| `content/figs/` | รูปประกอบ SVG 48 รูป เนื้อหาอ้างด้วยบรรทัด `{{fig:ชื่อ \| คำอธิบาย}}` |
| `content/papers/` | คลัง paper ตามสไลด์ รายสัปดาห์ |
| `content/audit/` | ผลตรวจเทียบกับข้อสอบ mock และตารางความครอบคลุมรายสไลด์ |
| `build_site.py` | สร้างหน้าเว็บจาก `content/` |
| `site/index.html` | เว็บไฟล์เดียว เปิดด้วยเบราว์เซอร์ได้เลย |
| `site/nlp-final-study.artifact.html` | ไฟล์เดียวกันในรูปแบบสำหรับเผยแพร่เป็น Artifact |
| `exam-prep/` | ชุดข้อสอบจำลอง (`mock_exam.html`, คลังข้อสอบใน `subjects/`), โน้ตรายสัปดาห์ `notes/`, `MEMORIZE_LIST.md`, `CHEATSHEET_A4_handwrite.md`, คำใบ้ของอาจารย์ `source/nlp_exam_hints.md` (คัดลอกมาจาก team-project ไม่รวมไฟล์ log ของการสร้างข้อสอบ 8 ไฟล์) |

## วิธีสร้างเว็บใหม่

ต้องมี Python 3 และแพ็กเกจ `markdown`

```bash
pip install markdown
python build_site.py
```

แล้วเปิด `site/index.html` ในเบราว์เซอร์ ฟอนต์ไทยดึงจากอินเทอร์เน็ต ถ้าออฟไลน์จะใช้ฟอนต์ระบบแทน

## ข้อควรรู้เรื่องที่มาของเนื้อหา

- เนื้อหาเขียนจากสไลด์ เดโม และคำใบ้ของอาจารย์ แล้วเทียบกับคลังข้อสอบ mock ของผู้ใช้ ส่วนที่เกินสไลด์ติดป้าย "(ต่อยอดจากสไลด์)" หรือ "(นอกสไลด์)" และเว็บแสดงเป็นแถบสีม่วง
- เนื้อหาส่วนใหญ่เขียนและเติมโดย AI (ซับเอเจนต์) ยังไม่ได้ตรวจทีละประโยคโดยคน ตัวเลขในชุดฝึกคำนวณตรวจด้วย python
- ตัวเลขในสไลด์ขัดกับเดโมหรือคำใบ้หลายจุด รายละเอียดอยู่ใน `content/audit/` ตอนสอบให้ตามค่าที่โจทย์ระบุ
- ลิงก์ใน `content/papers/` ตรวจจากหน้า abstract เป็นส่วนใหญ่ บางรายการยืนยันได้แค่จากผลค้นหา ซึ่งแต่ละรายการระบุไว้
